## 📤 影片上傳完整教學

### 🆕 新功能：支援三種上傳方式

系統現在支援 **三種** 影片上傳方式：

#### 1️⃣ MP4 影片檔（本地上傳）
- **格式**：`.mp4`
- **建議**：適合一般錄影檔案
- **處理**：自動轉檔為網頁優化格式
- **大小限制**：最大 512MB

#### 2️⃣ EverCam ZIP 檔（本地上傳）
- **格式**：`.zip`
- **內容**：包含影片 + 簡報同步資料
- **優勢**：支援章節跳轉、講義同步顯示
- **大小限制**：最大 512MB

#### 3️⃣ 🆕 影片連結（外部連結）
- **格式**：HTTP/HTTPS URL
- **支援類型**：
  - EverCam index.html 連結（推薦）
  - MP4 直連
- **優勢**：
  - ✅ 無需上傳檔案
  - ✅ 立即可播放（skip壓縮）
  - ✅ 節省伺服器空間
- **限制**：需確保連結長期有效

## 🔗 影片連結上傳詳解

### 📌 什麼是影片連結上傳？

**影片連結上傳**允許您提供外部影片 URL，而非上傳實體檔案。系統會直接使用該連結播放影片。

### 🎯 適用情境

**適合使用連結的情況**：
- ✅ 影片已存放在其他雲端服務
- ✅ 檔案過大不適合上傳
- ✅ 希望節省伺服器儲存空間
- ✅ 影片已有固定網址（如 EverCam 已匯出網頁）

**不適合的情況**：
- ❌ 連結可能失效或變更
- ❌ 影片需要嚴格權限控制
- ❌ 希望由系統管理檔案

### 🔗 支援的連結格式

#### 格式 1：EverCam index.html 連結（推薦）

**範例**：
```
http://example.com/videos/speech123/index.html
https://cdn.example.com/evercam/abc/index.html
```

**特點**：
- ✅ 系統自動識別為 EverCam 格式
- ✅ 自動載入 config.js 設定檔
- ✅ 支援完整 EverCam 互動功能（章節、講義同步）

**系統處理方式**：
- 儲存路徑：`http://example.com/videos/speech123/media.mp4`（佔位符）
- Config.js：`http://example.com/videos/speech123/config.js`（自動載入）
- 格式標記：`evercam`

**重要**：請使用 `index.html` 連結，不要直接貼 `media.mp4`，以確保 EverCam 功能正常運作。

#### 格式 2：MP4 直連

**範例**：
```
http://example.com/videos/lecture.mp4
https://cdn.example.com/content/speech.mp4
```

**特點**：
- ✅ 標準 MP4 播放器
- ✅ 簡單直接

**系統處理方式**：
- 儲存路徑：原始 URL
- 格式標記：`mp4`

## ⚙️ 自動轉檔系統（更新）

### 轉檔機制

#### 本地檔案上傳（MP4/ZIP）

上傳成功後，影片**不會立即可觀看**，需經過轉檔處理：

1. **狀態：排隊中 (pending)**
   - 影片已上傳，等待 Worker 處理
   - 在轉檔佇列中排隊

2. **狀態：處理中 (processing)**
   - Worker 正在轉檔
   - 優先嘗試 GPU 加速
   - 同時生成縮圖（如果未上傳）

3. **狀態：完成 (ready)**
   - 轉檔成功
   - 影片出現在首頁列表

4. **狀態：錯誤 (error)**
   - 轉檔失敗
   - 查看錯誤訊息並重新上傳

#### 🆕 連結上傳

**跳過轉檔，直接可看**：

1. **上傳後立即 `ready`**
   - ✅ 無需等待轉檔
   - ✅ 立即顯示在首頁
   - ✅ 使用者可直接觀看

2. **不檢查壓縮模式**
   - ✅ 不論系統或院區壓縮設定
   - ✅ 連結影片一律跳過

3. **不觸發 Worker**
   - ✅ 不占用轉檔資源
   - ✅ 不進入佇列

**為什麼跳過轉檔？**
- 連結影片沒有本地檔案
- 無法進行壓縮處理
- 由外部服務器提供影片

## 🎬 URL 格式判定邏輯

### 系統如何識別連結格式？

當您貼上影片連結時，系統會自動分析 URL 並判定格式：

```
解析 URL → 取得檔名
              ↓
    是否為 index.html?
         ↙          ↘
       是            否
       ↓             ↓
   EverCam      檢查副檔名
                    ↓
              是否為 .mp4?
              ↙         ↘
            是           否
            ↓            ↓
          MP4        EverCam
```

### 格式判定規則

| URL 結尾 | 判定格式 | 儲存方式 | 播放器 |
|---------|---------|---------|--------|
| `index.html` | EverCam | 目錄/media.mp4 | EverCam 播放器 + config.js |
| `.mp4` | MP4 | 原始 URL | 標準 MP4 播放器 |
| 其他副檔名 | EverCam（假設） | 原始 URL | EverCam 播放器 |

### 範例

#### 範例 1：EverCam index.html
```
輸入：http://example.com/videos/abc/index.html
儲存：http://example.com/videos/abc/media.mp4
Config：http://example.com/videos/abc/config.js
格式：evercam
```

#### 範例 2：標準 MP4
```
輸入：http://cdn.test.com/lecture.mp4
儲存：http://cdn.test.com/lecture.mp4
格式：mp4
```

#### 範例 3：其他格式
```
輸入：http://example.com/video.avi
儲存：http://example.com/video.avi
格式：evercam（假設）
```

- ❌ 貼上失效的連結

## 🔍 防呆機制說明

### 使用者介面防呆

#### 1. 動態禁用欄位

**選擇檔案時**：
- 檔案欄位：正常
- 連結欄位：禁用（灰色背景）
- 連結內容：自動清空

**輸入連結時**：
- 連結欄位：正常
- 檔案欄位：禁用（灰色背景）
- 檔案選擇：自動清空

#### 2. 動態 required 屬性

- 選擇檔案 → `required` 設在檔案欄位
- 輸入連結 → `required` 設在連結欄位
- 確保至少填寫一個

#### 3. 視覺化回饋

- 禁用欄位顯示灰色背景（#f1f5f9）
- 圖示提示（ℹ️）
- 清晰的說明文字

### 送出前驗證

#### JavaScript 驗證（前端）

```javascript
// 檢查 1：是否至少填一個？
if (!hasFile && !hasLink) {
    alert('請選擇上傳檔案或提供影片連結。');
    return false;
}

// 檢查 2：是否只填一個？
if (hasFile && hasLink) {
    alert('請只選擇一種上傳方式：檔案上傳或影片連結。');
    return false;
}
```

#### PHP 驗證（後端）

```php
// 雙重檢查確保資料正確
if ($using_link && $using_file) {
    throw new Exception("請選擇檔案上傳或連結輸入其中一種方式。");
}

if (!$using_link && !$using_file) {
    throw new Exception("請上傳影片檔案或提供影片連結。");
}
```

### URL 格式驗證

#### 檢查項目

1. **格式驗證**
   ```php
   filter_var($url, FILTER_VALIDATE_URL)
   ```

2. **協定檢查**
   ```
   只允許 http:// 或 https://
   ```

3. **結構解析**
   ```
   parse_url() 確保 URL 結構完整
   ```

## ❓ 常見問題（更新）

### Q1: 連結上傳和檔案上傳有什麼差別？

**A**:
| 項目 | 檔案上傳 | 連結上傳 |
|------|---------|---------|
| 儲存位置 | 本地伺服器 | 外部伺服器 |
| 需要轉檔 | 是 | 否 |
| 立即可看 | 否（需等轉檔） | 是 |
| 占用空間 | 是 | 否 |
| 檔案管理 | 系統控制 | 外部控制 |

### Q2: EverCam 該貼什麼連結？

**A**: **一定要貼 `index.html` 連結！**

✅ **正確**：
```
http://example.com/videos/abc/index.html
```

❌ **錯誤**：
```
http://example.com/videos/abc/media.mp4
```

**原因**：`index.html` 連結讓系統正確識別為 EverCam，並載入 `config.js` 以支援互動功能。

### Q3: 連結上傳的影片為什麼不需要轉檔？

**A**: 因為連結影片沒有上傳本地檔案，無法進行轉檔處理。影片由外部伺服器直接提供，系統只儲存連結。

### Q4: 我可以同時上傳檔案和貼連結嗎？

**A**: **不行！** 系統有防呆機制，只能選擇一種方式：
- 選擇檔案後，連結欄位會自動禁用
- 輸入連結後，檔案欄位會自動禁用
- 送出前會再次驗證

### Q5: 連結上傳後可以改回檔案上傳嗎？

**A**: 可以！在「編輯影片」頁面：
1. 找到該影片
2. 點擊「編輯」
3. 上傳新檔案（連結欄位留空）
4. 儲存後會重新進入轉檔佇列

### Q6: 連結失效了怎麼辦？

**A**: 如果外部連結失效，影片將無法播放。您可以：
1. 更新為新的有效連結
2. 或改為上傳檔案

### Q7: 可以用什麼格式的URL？

**A**: 
- ✅ `http://example.com/video.mp4`
- ✅ `https://cdn.example.com/abc/index.html`
- ❌ `ftp://server.com/video.mp4`（不支援 FTP）
- ❌ `file:///C:/video.mp4`（不支援本地路徑）

```
5. 狀態 → ready
```

### 播放器選擇邏輯

`watch.php` 根據 `format` 欄位決定播放器：

```php
if ($format === 'evercam') {
    // 使用 EverCam 播放器
    // 嘗試載入 config.js
    $config_url = dirname($content_path) . '/config.js';
} else {
    // 使用標準 MP4 播放器
```
