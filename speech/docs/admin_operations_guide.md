## 🎬 影片管理

### 新增影片（上傳）

#### 📍 操作路徑
```
登入 → 導覽列「影片」→ 點擊「新增影片」→ 填寫表單 → 開始上傳
```

#### 📝 詳細步驟

**步驟 1：進入影片管理頁面**
1. 確認已登入系統
2. 在頁面上方導覽列找到 **「影片」** 按鈕（有影片圖示 📹）
3. 點擊進入影片管理頁面

**步驟 2：點擊新增影片**
1. 在影片管理頁面上方找到 **「新增影片」** 按鈕（綠色，有 ➕ 圖示）
2. 點擊進入上傳頁面

**步驟 3：填寫基本資訊**

| 欄位 | 操作說明 | 必填 | 範例 |
|------|---------|------|------|
| 演講標題 | 輸入影片標題 | ✅ 是 | `心臟醫學新趨勢研討會` |
| 所屬院區 | 下拉選單選擇 | ✅ 是 | `大林` |
| 演講日期 | 點擊日期選擇器 | ✅ 是 | `2026-01-27` |
| 講者姓名 | 輸入講者全名 | ✅ 是 | `王大明` |
| 服務單位 | 輸入所屬醫院/科室 | ❌ 否 | `台中慈濟醫院心臟科` |
| 職務 | 輸入職稱 | ❌ 否 | `主治醫師` |

**步驟 4：上傳縮圖（選填）**
1. 找到 **「上傳縮圖 (JPG/PNG)」** 欄位
2. 點擊 **「選擇檔案」** 按鈕
3. 選擇圖片檔案（建議 1280x720 像素）
4. 確認選擇

> 💡 **提示**：如果不上傳縮圖，系統會自動從影片第 1 秒擷取畫面。

**步驟 5A：上傳影片檔案**
1. 找到 **「上傳 mp4 或 evercam zip 檔」** 欄位
2. 點擊 **「選擇檔案」** 按鈕
3. 選擇影片檔案：
   - **MP4 檔案**：直接選擇 `.mp4`
   - **EverCam ZIP**：選擇從 EverCam 匯出的 `.zip` 檔案
4. 確認選擇
5. **注意**：檔案大小限制 512MB

**步驟 5B：🆕 使用影片連結（二選一）**
1. 找到 **「或 貼上影片連結」** 欄位
2. 貼上影片 URL：
   - **EverCam（推薦）**：`http://example.com/videos/abc/index.html`
   - **MP4 直連**：`http://cdn.example.com/video.mp4`
3. 檔案上傳欄位會自動禁用（灰色）

> ⚠️ **重要**：只能選擇「檔案上傳」或「貼上連結」其中一種！

**步驟 6：開始上傳**
1. **檢查所有欄位**是否填寫正確
2. 點擊頁面底部的 **「開始上傳」** 按鈕
3. 等待上傳：
   - 會顯示上傳進度條
   - 顯示百分比
   - **請勿關閉頁面**

**步驟 7：確認上傳結果**

**檔案上傳成功**：
- ✅ 顯示綠色成功訊息
- 訊息內容：
  - 自動模式：「演講上傳成功！系統設為「自動壓縮」，已通知轉檔主機開始作業。」
  - 手動模式：「演講上傳成功！已加入「待處理清單」。請前往佇列管理頁面手動啟動壓縮。」
  - 無壓縮模式：「演講上傳成功！系統設為「無壓縮模式」，影片已可立即觀看。」

**連結上傳成功**：
- ✅ 顯示綠色成功訊息
- 訊息：「演講上傳成功！使用外部連結的影片已可立即觀看。」
- 影片**直接可在首頁看到**（不需等待轉檔）

**上傳失敗**：
- ❌ 顯示紅色錯誤訊息
- 查看錯誤原因並修正
- 重新上傳

### 編輯影片

#### 📍 操作路徑
```
登入 → 導覽列「影片」→ 找到影片 → 點擊「編輯」→ 修改 → 儲存修改
```

#### 📝 詳細步驟

**步驟 1：進入影片管理頁面**
1. 點擊導覽列 **「影片」** 按鈕
2. 看到所有影片列表

**步驟 2：找到要編輯的影片**
1. 瀏覽影片列表
2. 或使用搜尋功能：
   - 在頁面上方找到搜尋框（「搜尋影片標題或講者...」）
   - 輸入影片標題或講者姓名
   - 按 🔍 按鈕或 Enter 搜尋

**步驟 3：點擊編輯按鈕**
1. 找到目標影片的那一列
2. 在該列右側「操作」欄找到 **編輯圖示（✏️）**
3. 點擊進入編輯頁面

**步驟 4：修改資訊**

可修改的欄位：
- ✏️ 演講標題
- 📅 演講日期
- 🏥 所屬院區（系統管理員）
- 👤 講者姓名
- 🏢 服務單位
- 💼 職務

**步驟 5：更換縮圖（選填）**
1. 找到 **「目前縮圖」** 預覽
2. 下方有 **「更新縮圖（留空則保持不變）」**
3. 點擊選擇新圖片
4. 確認選擇

**步驟 6A：更換影片檔案（選填）**
1. 找到 **「更新 mp4 或 evercam zip 檔（留空則保持不變）」**
2. 點擊選擇新檔案
3. 選擇 MP4 或 ZIP 檔案
4. 舊檔案會被刪除
5. 新影片會重新進入轉檔佇列

**步驟 6B：🆕 更換為影片連結（選填）**
1. 找到 **「或 貼上影片連結（留空則保持不變）」**
2. 貼上新的影片 URL
3. 影片會立即設為可播放狀態

> 💡 **提示**：檔案和連結欄位都留空 = 保持原影片不變

**步驟 7：儲存修改**
1. 檢查所有修改是否正確
2. 點擊頁面底部 **「儲存修改」** 按鈕
3. 等待儲存完成
4. 看到成功訊息

### 刪除影片

#### 📍 操作路徑
```
登入 → 導覽列「影片」→ 找到影片 → 點擊「刪除」→ 確認
```

#### 📝 詳細步驟

**步驟 1：進入影片管理頁面**
1. 點擊導覽列 **「影片」** 按鈕

**步驟 2：找到要刪除的影片**
1. 在影片列表中找到目標影片
2. 或使用搜尋功能

**步驟 3：點擊刪除按鈕**
1. 在影片列右側「操作」欄找到 **刪除圖示（🗑️）**
2. 點擊

**步驟 4：確認刪除**
1. 彈出確認對話框
2. 對話框內容：「確定要刪除這個影片嗎？此操作無法復原！」
3. 點擊 **「確定」** 執行刪除
4. 或點擊 **「取消」** 放棄刪除

**步驟 5：確認刪除結果**
- ✅ 刪除成功：影片從列表中消失
- 系統會同時刪除：
  - 影片檔案
  - 縮圖
  - 資料庫記錄
  - 所有觀看進度記錄

> ⚠️ **警告**：刪除後無法復原！請謹慎操作。


#### 📝 詳細步驟

**步驟 1：進入公告管理**
1. 點擊導覽列 **「公告」** 按鈕（有喇叭圖示 📢）
2. 看到公告列表頁面

1. 找到頁面上方的 **「新增公告」** 按鈕（綠色，有 ➕ 圖示）
2. 點擊進入新增表單

**步驟 3：填寫公告資訊**

| 欄位 | 說明 | 必填 | 範例 |
|------|------|------|------|
| 標題 | 公告標題 | ✅ 是 | `心臟醫學研討會` |
| 所屬院區 | 下拉選單 | ✅ 是 | `大林` |
| 講者姓名 | 講者名稱 | ❌ 否 | `王大明` |
| 服務單位 | 講者單位 | ❌ 否 | `心臟科` |

| 地點 | 演講地點 | ❌ 否 | `大會議室` |
| 詳細內容 | 公告詳細說明 | ❌ 否 | 多行文字 |
| 圖片 URL | 公告圖片連結 | ❌ 否 | `http://...` |

**步驟 4：輪播設定（選填）**

> 📌 **什麼是輪播公告？**  
> 輪播公告會顯示在首頁最上方的輪播區塊，以全螢幕圖片輪播方式呈現，非常醒目。

如果要在首頁輪播顯示：

1. 找到 **「在首頁輪播顯示」** 勾選框
2. ✅ 勾選此選項
3. 填寫輪播時間範圍：
   - **輪播開始日期**（選填）：輪播開始顯示的日期
   - **輪播結束日期**（選填）：輪播停止顯示的日期

#### 🔄 輪播顯示規則（重要！）

公告必須**同時滿足以下所有條件**才會在首頁輪播中顯示：

| 條件 | 說明 | 檢查時間 |
|------|------|---------|
| ✅ is_active = 1 | 公告必須啟用 | 系統檢查 |
| ✅ is_hero = 1 | 必須勾選「在首頁輪播顯示」 | 新增時勾選 |
| ✅ hero_start_date | `NULL` 或 `≤ 今天` | 每天自動檢查 |
| ✅ hero_end_date | `NULL` 或 `> 今天` | 每天自動檢查 |

**時間檢查邏輯**：
```sql
WHERE is_active = 1 
  AND is_hero = 1
  AND (hero_start_date IS NULL OR hero_start_date <= CURDATE())
  AND (hero_end_date IS NULL OR hero_end_date > CURDATE())
```

**⚠️ 注意結束日期的判斷**：
- `hero_end_date > CURDATE()` 表示「結束日期當天不顯示」
- 例如：結束日期設 `2026-02-28`，則 2/27 最後一天顯示，2/28 就不顯示了

#### 📅 輪播時間範例

**範例 1：永久輪播**
```
輪播開始日期：（空白）
輪播結束日期：（空白）
→ 勾選後立即顯示，永久輪播
```

**範例 2：限時活動（2 月份）**
```
輪播開始日期：2026-02-01
輪播結束日期：2026-03-01
→ 2/1 開始顯示，2/28 最後一天顯示
→ 3/1 起不再顯示
```

**範例 3：預約上架**
```
輪播開始日期：2026-03-01（未來日期）
輪播結束日期：（空白）
→ 3/1 之前不顯示
→ 3/1 起開始顯示，無結束日期
```

**範例 4：單日活動**
```
輪播開始日期：2026-02-15
輪播結束日期：2026-02-16
→ 僅在 2/15 這一天顯示
→ 2/16 起不再顯示
```

#### 🗓️ 一般公告列表自動隱藏規則

**除了輪播設定外，還有一般公告列表的顯示規則**：

在公告列表頁面（非輪播），系統會根據「演講日期」自動隱藏過期公告：

| 欄位 | 判斷邏輯 | 說明 |
|------|---------|------|
| event_date | `>= CURDATE()` | 演講日期 ≥ 今天才顯示 |

**實際邏輯**：
```sql
WHERE event_date >= CURRENT_DATE AND is_active = 1
```

**📌 重要差異**：

| 類型 | 控制欄位 | 自動隱藏條件 |
|------|---------|-------------|
| 輪播公告 | `hero_start_date`, `hero_end_date` | 依輪播時間範圍 |
| 一般公告 | `event_date` | 演講日期過期自動隱藏 |

**範例說明**：
```
公告 A：
  - 勾選「輪播顯示」
  - 輪播開始：2026-02-01
  - 輪播結束：2026-02-28
  - 演講日期：2026-02-15

顯示情況：
  ✅ 2/1~2/14：在輪播中顯示 + 在公告列表顯示
  ✅ 2/15：在輪播中顯示 + 在公告列表顯示（當天）
  ✅ 2/16~2/28：在輪播中顯示 + 在公告列表不顯示（已過期）
  ❌ 3/1 起：輪播結束，公告列表也不顯示
```

**💡 最佳實踐**：
1. **短期活動**：設定輪播結束日期，避免過期還在輪播
2. **長期公告**：不設結束日期，需要時手動取消勾選輪播
3. **演講日期**：一定要設定！公告列表會根據這個自動過濾
4. **測試建議**：設定完成後，到首頁確認輪播是否正常顯示

**步驟 5：儲存公告**
1. 檢查所有欄位
2. 點擊 **「儲存」** 按鈕
3. 看到成功訊息
4. 返回公告列表

1. 點擊導覽列 **「公告」** 按鈕
2. 找到 **「批次上傳公告」** 按鈕

**步驟 4：上傳 Excel 檔案**
1. 返回批次上傳頁面
2. 找到 **「選擇檔案」** 按鈕
3. 選擇剛才填寫的 Excel 檔案
4. 點擊 **「上傳」** 或 **「批次匯入」** 按鈕

**步驟 5：確認匯入結果**
1. 系統顯示匯入進度
2. 成功訊息：「成功匯入 X 則公告」
3. 返回公告列表查看

> ⚠️ **注意**：
> - 院區管理員只能上傳自己院區的公告
> - CSV 檔案可能有編碼問題，建議使用 `.xlsx`


#### 📝 詳細步驟

**步驟 2：進入轉檔排程管理**
1. 在頁面上方找到 **「轉檔排程管理」** 按鈕（有清單圖示 ✓）
2. 點擊進入轉檔佇列頁面

**步驟 3：查看佇列資訊**

頁面顯示內容：
- 📊 **統計資訊**
  - 等待中的影片數量
  - 處理中的影片數量
  - 錯誤的影片數量

  - 縮圖
  - 標題
  - 講者
  - 院區
  - 上傳時間
  - **狀態**

**步驟 4：理解狀態標示**

| 狀態 | 圖示 | 說明 | 行動 |
|------|------|------|------|
| waiting | 🟡 | 等待手動觸發 | 需手動勾選並開始轉檔 |
| pending | 🟡 | 排隊中 | 等待 Worker 處理 |

3. 將滑鼠移到驚嘆號上查看詳細錯誤訊息
4. 根據錯誤訊息決定處理方式：
   - 檔案損壞 → 重新上傳
   - 格式不支援 → 轉換格式後上傳
   - 空間不足 → 聯繫系統管理員

## ❓ 常見問題

### Q1: 我找不到上傳影片的地方？
**A**: 請依序操作：
1. 點擊導覽列 **「影片」** 按鈕
2. 在影片管理頁面點擊 **「新增影片」** 按鈕（綠色，有 ➕）
3. 確認帳號有管理員權限

### Q2: 上傳後影片在哪裡？
**A**: 
- 檔案上傳 → 進入轉檔佇列 → 完成後出現在首頁
- 連結上傳 → 立即在首頁顯示
- 查看轉檔進度：導覽列「影片」→「轉檔排程管理」

### Q3: 如何知道影片轉檔完成？
**A**: 
1. 導覽列「影片」→「轉檔排程管理」
2. 狀態變為 **已完成**（綠色 🟢）時完成
3. 或直接在首頁查看是否出現

### Q4: 批次上傳公告失敗？
**A**: 檢查：
1. 使用 `.xlsx` 格式（非 `.csv`）
2. 日期格式正確（YYYY/MM/DD）
3. 必填欄位（標題、院區）已填寫
4. 院區名稱正確（大林/花蓮/台中/台北）

### Q5: 影片刪除後可以恢復嗎？
**A**: **不行！** 刪除後無法復原，請謹慎操作。
