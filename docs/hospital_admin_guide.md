# 院區管理員介面完整功能說明書

## 系統概述

院區管理員介面是一套專為醫院教育訓練管理者設計的後台管理系統。系統整合 **Moodle 學習管理平台** 與 **Portal 入口系統**，提供完整的課程管理、人員管理、群組管理等功能。

### 系統特色
- 🏥 **多院區架構**：每位院區管理員只能管理所屬院區的資源
- 🔗 **雙系統整合**：Portal 與 Moodle 資料即時同步
- 📱 **響應式設計**：支援桌面與行動裝置
- ⚡ **即時操作**：所有變更即時生效

## 📁 2. 類別管理

> 檔案位置：`templates/tabs/hospital_admin_categories.php`

### 功能說明
管理 Moodle 課程類別的層級結構，設定必修類別與學習要求。

### 主要功能

#### 2.1 類別瀏覽
- **樹狀目錄瀏覽**：逐層進入子類別
- **麵包屑導覽**：顯示當前路徑，可快速返回上層
- **類別資訊顯示**：
  - 類別ID
  - 類別名稱
  - 課程數量
  - 子類別數量
  - ⭐ 必修標記（橘紅色「必修」標籤）

#### 2.2 類別操作
| 操作 | 說明 |
|------|------|
| 新增類別 | 在當前層級建立新的子類別 |
| 編輯名稱 | 修改類別名稱 |
| 刪除類別 | 刪除空類別（僅限無課程、無子類別時可刪除）|
| ⚙️ 類別設定 | 開啟類別設定彈窗 |

#### 2.3 類別設定（重要功能）

##### 基本設定
| 設定項目 | 說明 |
|----------|------|
| 設為必修類別 | 勾選後，此類別會在學員首頁強制顯示進度 |
| 需通過課程數 | 設定學員需完成的課程數量（0 = 動態，選幾堂亮幾燈）|
| 完成期限 | 設定需在幾個月內完成（0 = 無期限）|
| 按順序完成 | 要求學員依課程排序順序完成 |

##### 必修對象篩選（進階功能）
當勾選「設為必修類別」後，可設定此必修的適用對象：

| 篩選維度 | 說明 | 範例 |
|----------|------|------|
| 職類 | 職業類別 | 護理師、醫師、藥師 |
| 所屬 | 部門/單位 | 內科部、急診室、門診區 |
| 屬性 | 人員屬性 | 正職、實習生、約聘人員 |

- **OR 條件組**：可新增多組篩選條件，符合任一組即適用
- **搜尋符合人員**：即時預覽符合條件的人員清單
- **設定必修要求**：將必修要求儲存至符合條件的人員

## 📚 3. 課程管理

> 檔案位置：`templates/tabs/hospital_admin_courses.php`

### 功能說明
管理院區內所有 Moodle 課程，包含課程的新增、刪除、必修設定等。

### 主要功能

#### 3.1 類別導覽
- 顯示當前類別的所有子類別按鈕
- 點擊可進入子類別查看課程
- 顯示每個類別的課程數量

#### 3.2 課程列表
| 欄位 | 說明 |
|------|------|
| 勾選框 | 用於批次選擇 |
| ID | Moodle 課程 ID |
| 課程名稱 | 課程全名（必修課程前有 ⭐ 金星圖示）|
| 簡稱 | 課程簡稱 |
| 狀態 | 顯示/隱藏 |
| 操作 | 必修標記、進入課程、刪除 |

#### 3.3 課程操作

| 操作 | 圖示 | 說明 |
|------|------|------|
| 標記必修 | ⭐ | 點擊星星切換必修狀態（金色=必修）|
| 進入課程 | 🔗 | 直接連結至 Moodle 課程頁面 |
| 刪除課程 | 🗑️ | 刪除單一課程（需確認）|
| 批次刪除 | 🗑️ | 選擇多個課程後一次刪除 |

#### 3.4 新增課程
- 填寫課程全名與簡稱
- 自動建立在當前類別下
- 可設定初始為隱藏狀態

## 👥 4. 成員管理

> 檔案位置：`templates/tabs/hospital_admin_members.php`

### 功能說明
管理院區的所有成員帳號，提供新增、編輯、刪除等功能。

### 主要功能

#### 4.1 成員列表
| 欄位 | 說明 |
|------|------|
| 姓名 | 使用者全名 |
| 帳號 | 登入帳號 |
| Email | 電子郵件 |
| 角色 | 學員/開課教師 |

#### 4.2 成員操作
- **新增成員**：填寫帳號、姓名、Email、密碼、角色
- **編輯成員**：修改基本資料
- **刪除成員**：刪除帳號（同步刪除 Moodle 帳號）

#### 4.3 批次匯入（CSV）
支援批次建立帳號：

**CSV 格式**：
```
帳號,姓名,Email,密碼,角色,群組,標籤
user01,王小明,xm@hospital.org,Pass123!,學生,護理部,PGY 2026新進
user02,陳大華,dh@hospital.org,Pass456!,開課教師,內科部,臨床教師
```

**匯入設定**：
- 預設角色：當 CSV 未指定時套用
- 預設群組：當 CSV 未指定時套用
- 即時顯示匯入結果（成功/失敗筆數）

## 🏷️ 6. 群組管理

> 檔案位置：`templates/tabs/hospital_admin_cohorts.php`

### 功能說明
管理 Moodle Cohort（群組/世代），以維度分類方式組織人員。

### 維度說明

| 維度 | 用途 | 範例 |
|------|------|------|
| 職類 | 職業分類 | 護理師、醫師、藥師、放射師、行政人員 |
| 所屬 | 工作地點/部門 | 9A病房、急診室、門診區、開刀房 |
| 屬性 | 人員特性 | 正職、約聘、實習、PGY、主管 |

### 主要功能

#### 6.1 維度分頁
- 切換「職類」「所屬」「屬性」三個分頁
- 每個分頁顯示該維度下的所有群組
- 顯示每個群組的成員數量

#### 6.2 群組操作
| 操作 | 說明 |
|------|------|
| 新增群組 | 在指定維度下建立新群組 |
| 編輯群組 | 修改群組名稱 |
| 刪除群組 | 刪除群組（成員會移除關聯）|
| 管理成員 | 開啟成員管理面板 |

#### 6.3 成員管理面板
- 顯示群組內所有成員
- 搜尋院區內人員加入群組
- 批次加入/移除成員
- 顯示成員資訊（姓名、帳號、Email 等）

## 權限說明

### 角色層級

| 角色 | 說明 | 權限範圍 |
|------|------|----------|
| 學員 | 一般使用者 | 只能學習課程 |
| 開課教師 | 課程建立者 | 管理自己的課程 |
| 院區管理員 | 院區管理者 | 管理所屬院區所有資源 |
| 系統管理員 | 最高權限 | 管理所有院區 |

### 院區管理員權限範圍

院區管理員只能存取 `management_category_id` 以下的資源：
- ✅ 該院區類別下的課程
- ✅ 該院區的成員（透過群組關聯）
- ✅ 該院區的群組
- ❌ 其他院區的任何資源

## 常見操作流程

### 流程 1：設定必修類別

1. 進入 **類別管理**
2. 瀏覽至目標類別
3. 點擊該類別的 ⚙️ **類別設定** 按鈕
4. 勾選 **「設為必修類別」**
5. 設定 **需通過課程數**（例如：3 堂）
6. 設定 **完成期限**（例如：12 個月 = 每年需完成）
7. 選擇 **必修對象**：
   - 選擇維度條件（如：職類 = 護理師）
   - 點擊「搜尋符合人員」預覽
   - 點擊「設定必修要求」儲存
8. 點擊 **儲存設定**

### 流程 2：標記必修課程

1. 進入 **課程管理**
2. 瀏覽至目標類別
3. 找到要標為必修的課程
4. 點擊課程旁的 ☆ **星星按鈕**
5. 星星變為 ★ 金色表示已設為必修
6. 課程名稱前方會出現金星圖示

### 流程 3：批次匯入成員

1. 進入 **人員管理**
2. 點擊 **批次匯入** 按鈕
3. 準備 CSV 格式資料：
   ```
   user01,王小明,xm@hospital.org,Pass123!,學生,護理部,PGY
   user02,陳大華,dh@hospital.org,Pass456!,老師,內科部,臨床教師
   ```
4. 設定預設角色與群組
5. 貼上資料或上傳檔案
6. 點擊 **確認並開始匯入**
7. 檢視匯入結果

### 流程 4：建立新群組並加入成員

1. 進入 **群組管理**
2. 選擇維度分頁（如：職類）
3. 點擊 **新增群組**
4. 輸入群組名稱（如：「2026年度實習生」）
5. 群組建立後，點擊 **管理成員**
6. 搜尋要加入的人員
7. 點擊 ➕ 加入群組
